# Установка на Redmi Note 11 Pro, Android 12 / MIUI 13.0.6

## Почему раньше появлялось «Не удалось обработать пакет»
Предыдущие `base-1.apk`, `TouchX_Sensitivity_Fixed.apk` и `TouchX_Sensitivity_Low_Latency.apk` имеют `minSdkVersion=34`: Android 14+, а на телефоне Android 12 (API 31). Их устанавливать на этот телефон нельзя.

**Этот ZIP — проект с исходниками, НЕ установочный APK.** Файл ZIP открывать в установщике Android бессмысленно.

## Сборка
1. Создай новый репозиторий на GitHub.
2. Загрузи *содержимое* этого ZIP в корень репозитория. Убедись, что скрытая папка `.github/workflows/build.yml` сохранилась.
3. Открой Actions → `Build TouchX Android12 Debug APK` → Run workflow.
4. После зелёной сборки скачай её артефакт `touchx-android12-experimental` (это ZIP от GitHub), распакуй и найди `app-debug.apk`.
5. Перед установкой удали другие экспериментальные версии TouchX, если Android выдаёт конфликт подписи. Примечание: удаление очищает их локальные настройки.
6. Открой именно `app-debug.apk` в «Файлах» и установи.

## После установки
1. Запусти Shizuku и дай разрешение приложению.
2. Включи службу специальных возможностей TouchX.
3. Проверь отображаемый статус в TouchX, прежде чем запускать Free Fire.
4. При сообщении `MONITOR_INPUT` — это системный запрет Android/MIUI. Установка APK проблему **не решает**: в Shizuku без root перехват может быть недоступен.
5. При доступном мониторинге трижды быстро нажми **громкость вниз** для остановки (на MIUI действие нужно проверить). Есть ручная кнопка «СТОП». Лимита 120 секунд нет.

## Что гарантирует проект и что нет
- Минимальная версия API указана правильно: 31.
- APK генерируется в GitHub Actions на официальном Android SDK.
- Исходный проект не был проверен на физическом устройстве; сборка тоже не протестирована здесь.
- Android 12 не предоставляет обычным приложениям API для глобальной замены касаний. Shizuku под shell UID не равнозначен root.
- Если прав `MONITOR_INPUT` нет, работа TouchX в играх через этот механизм **невозможна**, даже если APK установится.
