# TouchX Redmi Note 11 Pro — проект для Android 12 (API 31)

Попытка переноса экспериментального TouchX на Redmi Note 11 Pro, MIUI 13.0.6, Android 12. Исходники. **Не готовый APK и не подтверждённая поддержка захвата касаний.**

## Отличия от версий TouchX для Android 14+
- `minSdk=31`, `targetSdk=32`; отдельно проверяется в GitHub Actions.
- Не вызывает Android 14-only `AccessibilityService.onMotionEvent`.
- Экспериментальный `InputMonitor` через Shizuku UserService, `injectInputEvent` через shell/root при разрешениях.
- При ошибке доступа `MONITOR_INPUT` показывает понятное сообщение вместо повторного запуска захвата при смене окна.
- Перехват запускается только при наличии активной Free Fire и выданных разрешений.
- Нет автоматического отключения через 120 секунд; экстренная остановка 3× «громкость вниз» или кнопка СТОП.
- Обработка ошибок подключения к Shizuku и периодическое обновление статуса.

**Важно**: Android 12 требует привилегию `android.permission.MONITOR_INPUT` для `monitorGestureInput`; ADB shell/Shizuku не всегда обладает ею. Это нельзя исправить заменой minSdk, и без root приложение может только показывать ошибку. Используй оригинальные настройки чувствительности Free Fire, если прав нет. Обход системных разрешений не реализован.

Подробные инструкции: `INSTALL_RU.md`. Исходный код: `app/src/main/java`.
